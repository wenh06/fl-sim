Tutorial: visualize and export results#

Every run writes .json logs (see Quickstart); fl-sim provides a visualization layer that turns them into publication-ready curves, both interactively in Jupyter and programmatically from plain Python. This tutorial covers both: merging a multi-seed experiment into one mean curve with error bounds, exporting it to PDF, and opening the interactive dashboard.

The full script lives at test-files/tutorial_visualization.py and is exercised in CI (everything except the dashboard rendering, which needs Jupyter). Prerequisites: Tutorial: your first controlled experiment.

The reference for all knobs (fonts, smoothing, widgets) is Visualization subsystem; this page is the workflow.

Preparing the logs#

The script trains the same FedAvg experiment under two seeds — the minimal “multi-seed” setup. Note the per-run tag: log file names carry it, so the two runs cannot overwrite each other (the same reasoning as in Tutorial: experiment matrices from the CLI):

from fl_sim.algorithms.fedopt import FedAvgClientConfig, FedAvgServer, FedAvgServerConfig
from fl_sim.data_processing.fed_synthetic import FedSynthetic

dataset = FedSynthetic(1.0, 1.0, True, 30)

# two seeds of the same experiment: the minimal multi-seed setup
for seed in (0, 1):
    server = FedAvgServer(
        # a fresh model per run: the server trains the model it is given
        # in place, so sharing one module would warm-start the second run
        dataset.candidate_models["mlp_d1"],
        dataset,
        FedAvgServerConfig(
            num_iters=3,
            num_clients=30,
            clients_sample_ratio=0.5,
            seed=seed,
            log_dir="t3_seeds",
            tag=f"seed_{seed}",  # distinct tag per seed: no log overwrites
        ),
        FedAvgClientConfig(batch_size=32, num_epochs=1),
    )
    server.train()

Merging seeds into one curve#

find_log_files collects the JSON logs; aggregate_results_from_json_log_with_custom_axis extracts a curve (step on x, acc on y here — any recorded metric works); plot_mean_curve_with_error_bounds merges the curves into a mean with an uncertainty band ("sem", "std", "quartile" or "iqr"). Saving the figure is plain matplotlib:

import matplotlib.pyplot as plt

from fl_sim.utils.viz import aggregate_results_from_json_log_with_custom_axis, find_log_files

# the runs above logged into the t3_seeds directory under fl-sim's log root
log_dir = Path(server._logger_manager.log_dir)
files = find_log_files(directory=log_dir, filters="seed_")
curves = [aggregate_results_from_json_log_with_custom_axis(f, part="val", x_metric="step", y_metric="acc") for f in files]

fig, ax = plt.subplots(figsize=(6, 4))
from fl_sim.utils.viz import plot_mean_curve_with_error_bounds

fig, ax = plot_mean_curve_with_error_bounds(curves, error_type="sem", label="FedAvg", fig_ax=(fig, ax))
ax.set_xlabel("cumulative communications")
ax.set_ylabel("val acc")
fig.savefig("fedavg-multi-seed.pdf", bbox_inches="tight")

This writes fedavg-multi-seed.pdf next to the working directory. Two remarks:

  • The x axis is the cumulative communication count — the metric Tutorial: your first controlled experiment dissected. Plotting against communications (rather than rounds) is what makes different communication-efficiency algorithms comparable in one figure.

  • With only two seeds the band is a range, not a statistic — use more seeds (just add more seed= runs; the merging code does not change).

Interactive exploration#

In a Jupyter notebook, the Panel dashboard performs all of the above interactively: it lists the log files it finds, plots selectable metrics, and provides sliders for smoothing, fonts and figure size, plus export to PDF/SVG/PNG:

from fl_sim.utils.viz import Panel

# in a Jupyter notebook this renders an interactive dashboard:
# pick log files, tune curves, export to PDF/SVG/PNG
panel = Panel(logdir="t3_seeds")

Run this cell in a notebook (JupyterLab, Colab, SageMaker, …) and the dashboard renders inline; see Visualization subsystem for a demo animation and the full feature list.
