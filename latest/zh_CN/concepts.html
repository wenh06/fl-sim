核心概念#

本页面是 fl-sim 的地图：每次实验的四个构件，以及一轮联邦训练中发生的事。它解释的是框架的*思考方式*——若想先动手体验，请从 快速上手 开始。

四个构件#

FedDataset——数据及其划分方式#

FedDataset 把原始数据集与 划分方案 打包在一起：它决定数据如何在模拟的客户端之间分布，并通过 get_dataloader(client_idx) 为每个客户端提供专属的 dataloader。内置数据集（FEMNIST、CIFAR10 等）在首次使用时下载； FedSynthetic 在本地生成合成数据，这也是本教程都能在几秒内跑完的原因。每个数据集还声明了 candidate_models——适合与它搭配的模型（如 quickstart 中的 dataset.candidate_models["mlp_d1"]）。数据集在 训练期间不可变 ：划分只做一次，且在训练开始前完成。自定义数据集见相应的 how-to 指南。

模型——普通的 PyTorch 模块#

模型就是普通的 torch.nn.Module 对象，fl-sim 不做任何包装。candidate_models 提供的或你自己带来的模型都可以用。服务器持有 全局 副本；每轮每个被采样的客户端拿到自己的副本，在本地数据切片上训练，再把结果发回。

服务器——调度者#

Server 持有全局模型与联邦调度（多少轮、多少客户端、如何采样），并驱动下文所示的循环。它从不触碰客户端本地数据。算法特定的行为都在子类里：FedAvgServer、FedProxServer 等 15 个以上——每个算法只定制少数几个定义良好的钩子：

  • communicate(target)——下行：服务器发给被采样客户端的内容（通常是当前全局模型）；

  • update()——聚合：客户端回复如何变成新的全局模型。

客户端——单个参与方的本地状态#

每个 Client 持有自己的模型副本、数据切片与训练状态。它的钩子与服务器互为镜像：

  • update()——本地训练：在本地数据上拟合收到的模型（本地 epoch 数、本地优化器——全部来自客户端配置）；

  • communicate()——上行：构建发回服务器的消息。消息是带类型的对象（ClientToServer），携带更新后的模型状态与算法特有的附加内容。

算法定制钩子，而不是循环#

fl-sim 内置 20 个注册算法——FedAvg、FedProx、SCAFFOLD、FedPD、ProxSkip、Ditto 等——它们全部运行在*同一个*循环里。一个算法只是一对配置类加上若干钩子覆写：FedProx 改动客户端的本地目标函数；SCAFFOLD 在上行里加入控制变量；FedPD 允许客户端*完全跳过*某些上行。框架按固定顺序（见下）调用这些钩子，因此算法与基础设施——日志、评估、可复现性、并行执行——正交组合，互不知晓。

注册自己的算法后，就能在 CLI 与实验矩阵中按名字使用它：

from fl_sim.algorithms._register import register_algorithm

@register_algorithm()
class MyServer(FedAvgServer):
    ...

参见

自定义算法的 how-to 指南给出了完整可运行的例子；Parallel execution layer 记录了钩子契约，保证自定义算法与所有执行后端兼容。

一轮训练#

server.train() 运行 num_iters 轮。每轮按固定顺序进行：

  1. 采样——服务器选出本轮的参与方（num_clients 中按 clients_sample_ratio 比例抽取）。

  2. 上行决策——因算法而异：多数算法让每个被采样客户端都响应；通信跳过型算法（FedPD、ProxSkip）在 此刻 于主线程上决定哪些客户端本轮上传。

  3. 下行广播——服务器把全局模型发给每个被采样客户端（server.communicate(target)）。

  4. 本地步——每个被选中的客户端依次执行评估 → 本地训练 → 构建上行消息。客户端之间互不可见，也看不到全局状态；它们只触碰自己的数据切片。

  5. 上行与聚合——回复 按被采样客户端的顺序 被消费，算法的 update() 产出新的全局模型。指标（服务器侧与每个客户端的）也在这里记录。

  6. 重复——共 num_iters 轮；日志与指标写入 ~/.cache/fl-sim/.logs/ （参见 快速上手）。

由于第 1–2 步与第 5 步在主线程上按固定顺序执行，无论第 4 步的本地步是串行执行还是在线程池上并发执行（Parallel execution layer）， 聚合算术 都完全一致。正是这条不变式让并行运行值得信赖。
