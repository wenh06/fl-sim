快速上手#

本页面介绍 fl-sim 上第一次联邦训练的完整流程：安装本包，在合成数据集上训练 FedAvg，并查看其产出的日志。整个运行在笔记本电脑上数秒内即可完成，既不需要下载数据集，也不需要 GPU。

核心概念见 核心概念 ；希望先了解概念的读者可从该页开始。

准备条件#

按照 安装说明 安装 fl-sim（pip install git+https://github.com/wenh06/fl-sim.git）。需要 Python 3.10+ 与 PyTorch。

训练第一个模型#

fl-sim 中的每次联邦训练都由三个对象构成： 数据集 （数据本身以及在客户端之间的划分方式）、 模型 （一个 PyTorch 模块，这里取自数据集内置的候选模型）和 服务器 （持有全局模型，负责采样客户端与聚合）。服务器配置承载联邦训练的调度（轮数、客户端数量、采样比例）；客户端配置承载本地训练方案。

from fl_sim.algorithms.fedopt import FedAvgClientConfig, FedAvgServer, FedAvgServerConfig
from fl_sim.data_processing.fed_synthetic import FedSynthetic

# a synthetic dataset split across 30 clients (no download needed)
dataset = FedSynthetic(1.0, 1.0, True, 30)
model = dataset.candidate_models["mlp_d1"]

server = FedAvgServer(
    model,
    dataset,
    FedAvgServerConfig(
        num_iters=5,
        num_clients=10,
        clients_sample_ratio=1.0,
        log_dir="quickstart",  # logs are written to ~/.cache/fl-sim/.logs/quickstart/
    ),
    FedAvgClientConfig(batch_size=32, num_epochs=1),
)
server.train()

上述代码可作为脚本运行，也可在 REPL 中执行。 FedSynthetic 在本地生成划分给 30 个客户端的合成分类数据集，不执行任何下载。 FedAvgServerConfig(num_iters=5, num_clients=10, clients_sample_ratio=1.0) 运行 5 轮，每轮从 30 个客户端中采样 10 个，且全部响应。 server.train() 执行完整的联邦循环；每轮的进度与指标将打印到控制台。

备注

server.train() 即 server.train("federated")。fl-sim 也可以用同样的对象运行 "centralized" 与 "local" 基线——参见 train() API。

日志文件#

每次运行的日志写入 ~/.cache/fl-sim/.logs/``（子目录可经服务器配置中的 ``log_dir= 覆盖，如本例所示）。上述脚本读回指标并打印结果：

log file: FedAvg-FedSynthetic-MLP_10-26_12-52.json
log file: FedAvg-FedSynthetic-MLP_10-26_12-52.txt
log file: config.json
Latest logged val/acc: 0.8767 (step 80)

每次运行产生三个文件：

  • 一个 .txt 日志，保存人类可读的控制台历史；

  • 一个 .json 日志，保存完整的指标历史，结构为 {"train": {...}, "val": {"Server": [...], "Client0": [...], ...}}——每次评估对应一个字典，包含 step、acc、loss 等字段。该文件是可视化所用的输入；

  • config.json——本次运行的确切服务器与客户端配置，便于日后复现每个实验。

备注

日志中的 step 统计的是**通信次数**，而不是轮数：每轮对每个被采样客户端包含一次下行广播与一次上行回复（这里每轮采样 10 个客户端，因此 step 每轮前进 20）。json 中的快照记录于每轮开始时，因此最终通信次数会大于最后一条日志的 step。

（具体精度数值可能因机器与包版本而异；在一种机器上，该运行的最终精度为 0.8767，初始时为 0.011——即 10 类任务的随机水平。）
